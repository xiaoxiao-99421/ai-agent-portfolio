Engineering Paradigm

统一工程范式

四个作品共用同一套轻量、可复现的实现方式，降低部署与维护成本。

⚙️
零额外 Web 依赖

服务端仅用 Python 标准库（http.server），无需 Flask / FastAPI 等框架，避免依赖冲突。

🔑
配置一处复用

LLM 配置（API 地址 / 密钥 / 模型）统一读取 rag-core/.env，其余作品自动回退复用。

🔒
同源规避跨域

前端由同一服务托管，避免浏览器 CORS 限制；API 密钥不暴露给前端。

Run Locally

本地运行指引

三步启动

  1. 配置 LLM：复制 rag-core/.env.example 为 rag-core/.env 并填入 API 地址、密钥与模型名。
  2. 一键启动（推荐）：在 求职作品集/ 目录下运行 python launch_all.py，一次性启动全部 4 个服务并自动打开本页；支持 --only rag,support 只启动部分。
  3. 手动启动：进入某个作品目录运行对应命令，如 cd doc-agent && python server.py --port 8002。
  4. 浏览器打开 http://localhost:端口 即可使用；多个作品可同时运行（端口不同，互不冲突）。
  5. 部分作品（如医疗 RAG）首屏会加载向量模型与向量库，响应稍慢属正常。
说明：演示用的知识库、订单、文档等数据均为仿真示例；接入真实系统只需替换数据来源与工具实现。医疗问答作品使用真实脱敏的医学问答数据。
